Orientation

How the tools fit together

The toolkit mirrors the life of a resource estimation study. Data arrives from the assay lab and has to be trusted before it can be understood, treated and finally modelled. The seven stages below are the order a geologist actually moves through — early stages gate the later ones, so a failed standard or a bad merge is caught before it contaminates a grade estimate.

1

Validate the incoming lab data

Before anything else, confirm the numbers loaded into the project database match what the laboratory actually reported on its certificates. Catch transcription and import errors at the door.

Data Verification
2

QA/QC the assays

Prove the assay data is reliable using the control samples inserted into the sample stream — reference standards, blanks, duplicates and umpire (check) assays. If the lab is drifting or contaminating, you find out here.

Explore the composited data

Understand the grade population domain by domain — its distribution, its relationships and how it behaves across geological boundaries. This is the exploratory data analysis that shapes every downstream decision.

Measure how tightly the drillholes sample each domain. Nearest-neighbour spacing underpins resource classification — Measured, Indicated, Inferred all hinge on how close the data really is.

The basics

Getting started

The app runs entirely in the browser — nothing to install. Open the hosted link, enter the shared passphrase, and pick a section from the left sidebar. Selecting a tool loads it in the main panel; ← Back returns to the section menu.

  • AccessThe app is gated by a single team passphrase. There are no individual accounts — anyone with the link and the passphrase can use every tool.
  • Two ways inEvery data tool accepts a file two ways: drag & drop / browse via the sidebar uploader, or “…or select from folder” to pick a file already sitting in the app's working directory.
  • Save this build⬇ Download this version in the sidebar zips up the exact codebase currently running, so you keep a working local copy even if the hosted app is later changed.
  • RerunsStreamlit re-runs the whole script on every input change — expect a brief flash as charts rebuild. That's normal, not a crash.
🔒
The passphrase protects internal tooling, not sensitive infrastructure. Treat any uploaded drillhole or assay file as project-confidential and share the link only within the team.

Data in

File input types

The toolkit reads three data formats plus two kinds of saved-settings file. Which formats a tool accepts depends on what it does — the sample and geostatistics tools speak native Datamine, while the QA/QC tools lean toward the CSV and Excel exports labs actually send.

FormatExtensionAccepted byNotes
CSV .csv Every tool The universal format. Any Excel sheet or Datamine table can be exported to CSV and read here.
Datamine .dm Plotting · Sample · Geostats · Block model Native Datamine data files, read directly — no export step. Offered wherever the tool works from drillhole composites.
Excel .xlsx .xls All QA/QC tools · Data Verification (.xlsx / .xlsm) Read straight from the workbook — lab certificates usually arrive as Excel, so no Save-As-CSV is needed.
Config .json QA/QC tools Saves your column mapping and filter choices. Download config JSON to keep it; Load config to restore the exact setup next time.
Settings folder file Capping · Statistics · Contact · DDH Spacing Load Settings recalls a saved parameter preset (fields, domains, capping levels) from the working folder.

The tools meet messy files halfway

  • Auto column mapOn upload, each QA/QC tool guesses which column is which — Lab, Element, Value, Date, Unit, CRM, Expected Value, SD — tolerant of case and spacing. Analyte → Element, Assay_Result → Value, certified value → Expected. Override any guess manually.
  • Wide → longIf a file has one column block per element (Au_EV, Au_SD, Au_or_ppm, Ag_EV…) instead of tidy Element/Value columns, a sidebar prompt offers to reshape it into the long format the tools expect.
  • Detection limitsIn Data Verification, censored lab values convert to numbers automatically: <0.5 becomes half the limit (0.25), >10000 becomes the limit — so they can be compared arithmetically.
  • Field guessingSample tools recognise common coordinate and key names on sight — X/Y/Z, EAST/NORTH/ELEV, BHID, HOLEID, LENGTH, ZONE/DOMAIN/ROCK — and pre-fill the field pickers.

5 tools
